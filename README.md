## Project Summary

In the Cloudflare app, open **Analysis & Reports > Project Summary** to see
your logged hours grouped by project and task across all weeks.

- Select a project, or keep **All projects**.
- Use **All time**, or choose **Date range** and enter inclusive From/To dates.
- Click **Apply** to update the totals and billable/non-billable breakdown.
- Expand a project to see task hours. Entries without a task appear as **(No task)**.
- Use **Export as PDF** to print or save the summary.

Totals include only the signed-in user's saved timesheet entries, not items on
the Today's Tasks board that have not been logged as time entries.
